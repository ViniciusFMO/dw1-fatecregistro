Vantagem do CSS Externo

  • Separação completa entre conteúdo (HTML) e desing (CSS)
  • Reutilização em multiplas páginas
  • Facilidade a manutenção do código
  • Melhor organização do projeto
  • Pode ser armazenado no cache do navegador, melhorando a performace
